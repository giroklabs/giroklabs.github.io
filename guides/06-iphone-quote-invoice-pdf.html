PC나 엑셀 없이 현장에서 단가표만 눌러 담고, 직인 찍힌 A4 PDF를 카톡·문자로 바로 보내는 방법입니다.

현장에서 견적서·거래명세서 보내는 4단계

  1. 처음 한 번만 내 사업자 정보(상호·입금 계좌)와 직인(이름 자동 생성 또는 도장 사진 배경 지우기)을 등록합니다.
  2. 품목 추가 화면에서 자주 쓰는 단가표를 톡 눌러 고르거나(엑셀·CSV 가져오기 지원), 카톡 주문 문자를 붙여넣어 수량을 채웁니다.
  3. 부가세(별도·포함·면세)와 할인을 고르면 합계와 일금 ○○원정이 자동으로 계산됩니다.
  4. 미리보기로 확인한 뒤 A4 PDF 또는 이미지(JPG)로 카톡·문자·메일로 바로 보냅니다.

작성 방식별 비교

방식 현장 즉시 전송 부가세·한글금액 계산 문서 전환(견적→명세서)
종이 양식 + 사진 촬영 글씨·조명 흐림 계산기로 수동 합산 새로 다시 작성
PC 엑셀·한글 양식 사무실 PC 복귀 필요 수식 깨짐 주의 파일 복사 후 수정
오픈견적 (아이폰) 1분 내 A4 PDF 카톡 전송 별도·포함·면세·원 미만 절사 자동 버튼 한 번으로 명세서·청구서·영수증 전환

자주 묻는 질문

Q. 거래처 정보나 단가표가 외부 서버에 저장되나요?
아니요. 작성한 문서와 단가표, 거래처 정보는 아이폰 기기 안에만 저장되며 JSON 백업 파일로 직접 내보내 보관할 수 있습니다(하단 배너 광고 SDK 제외).

Q. 세금계산서 발급도 되나요?
아니요. 오픈견적은 견적서·거래명세서·청구서·영수증 작성 앱이며 세금계산서(적격증빙) 발급 기능이 아닙니다. 전자세금계산서는 국세청 홈택스를 이용해 주세요.
