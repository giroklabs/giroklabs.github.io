거래처 사업자 휴·폐업 조회 & 명함 사진 자동 입력

처음 거래하는 업체에 견적서·거래명세서를 보내기 전 사업자 상태를 확인하고, 긴 상호·주소를 타자 치지 않고 채우는 방법입니다.

명함·사업자등록증 폰 안 글자 인식 · 지난번처럼 담기 지원
App Store에서 받기

타자 없이 거래처 입력·확인하는 4단계

  1. 받는 곳(거래처) 화면에서 명함 또는 사업자등록증 사진을 찍거나 앨범에서 고르면 기기 내 글자 인식으로 상호·대표자·사업자번호가 채워집니다.
  2. 상호나 주소를 몰라도 도로명주소 검색으로 정확한 주소를 바로 넣을 수 있습니다.
  3. 사업자 상태 확인 버튼을 눌러 해당 번호가 계속사업자(일반·간이과세자)인지 휴·폐업 상태인지 확인합니다.
  4. 한 번 보낸 거래처는 자동 저장되어, 다음 거래 때 '지난번처럼 담기'로 품목과 조건까지 한 번에 불러옵니다.

수동 입력 vs 오픈견적 자동 채우기

항목 직접 입력 오픈견적 사용 시
사업자번호·상호 입력 카톡·사진 보며 오타 주의해 입력 사진 글자 인식(기기 내) + 확인 후 바로 반영
휴·폐업 여부 확인 별도 사이트 접속 후 10자리 재입력 문서 작성 화면 안에서 바로 조회
반복 거래처 재작성 품목·부가세 조건 매번 새로 입력 '지난번처럼 담기'로 1초 재작성

자주 묻는 질문

Q. 거래처가 폐업 상태면 어떤 문제가 생기나요?
폐업한 사업자와 거래하면 세금계산서 발급이나 매입세액 공제가 불가능할 수 있으므로, 큰 거래나 선납품 전에는 사업자 상태를 미리 확인해 두세요.

Q. 휴·폐업 조회 결과만으로 법적 책임이 보장되나요?
공공데이터 API 조회 시점의 상태 안내이며, 실제 세무·계약 판단은 국세청 홈택스 공식 확인 및 계약서 기준을 함께 확인하셔야 합니다.
