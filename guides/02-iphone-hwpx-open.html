아이폰 HWPX 파일 3단계 열기

  1. 사파리·메일·카톡에서 .hwpx 파일을 내려받아 공유 버튼을 누릅니다.
  2. 앱 목록에서 오픈한글을 선택하면 본문과 표가 열립니다.
  3. 필요 시 내용을 수정해 저장하거나 PDF·이미지로 내보냅니다.

HWP와 HWPX 구조 차이

구분 .hwp .hwpx
문서 구조 기존 한컴 바이너리 포맷 국가표준(KS X 6101) XML 기반 포맷
모바일 열람 제약 iOS 기본 파일 앱 미지원 구형 HWP 전용 뷰어에서 미지원
해결 방법 HWP 지원 뷰어 사용 HWPX XML 구조를 지원하는 앱(오픈한글 등)으로 열람

자주 묻는 질문

Q. HWPX 파일도 수정 후 저장할 수 있나요?
네. 오픈한글에서는 HWP와 HWPX 모두 텍스트 수정·서식 변경 후 새 파일로 저장하거나 PDF·이미지로 변환할 수 있습니다.

Q. PC에서 작성한 표나 배치도 보이나요?
네. 본문과 표, 이미지 배치를 기기 안에서 렌더링해 보여줍니다. (일부 특수 서식은 PC 한글과 다르게 보일 수 있어 중요 문서는 원본을 함께 보관하세요.)
